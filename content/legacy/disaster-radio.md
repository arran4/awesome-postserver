# disaster.radio

**Assessment:** Historical / supporting infrastructure, not a main-list application.  
**Maturity:** Project paused. **Reviewed:** 2026-11-19.

[Source and project status](https://github.com/sudomesh/disaster-radio) · [Network model](https://github.com/sudomesh/disaster-radio/wiki/Layered-Model)

disaster.radio explored solar-powered, low-bandwidth LoRa networking for disaster and off-grid situations. The radio network can relay information without ordinary internet infrastructure, but an off-grid router or relay is **still infrastructure**.

## Why it is not an automatic Post-Server app

Running a separate solar radio node, repeater or routing device is not equivalent to having an ordinary desktop and mobile phone participate in stateful replication. The project's purpose is networking infrastructure; a persistent peer-owned end-user application would need to be demonstrated separately.

There is additional maintenance risk: the upstream repository states work is paused. Preserve this as a historical reference, not a recommendation for a current install.
