# Hyphanet — the original Freenet

**Assessment:** Historical ecosystem pending fresh verification of ordinary two-device operation.  
**Maturity:** Established historically; current maintenance to be verified. **Reviewed:** 2026-11-19.

[Hyphanet](https://www.hyphanet.org/) · [Original Freenet/Hyphanet code](https://github.com/hyphanet/fred)

Hyphanet is the descendant of **the original Freenet**: a decentralized content network known for publishing, storing and retrieving content, community discussions, and applications built on locally operated peers. Some early applications provided mail, forum and Usenet-like experiences; these are not assumed to be currently maintained.

It is **not** the same as [the new Freenet project](https://freenet.org/), which provides a distinct application architecture and modern projects including River.

## Server-optional considerations

Peer-operated storage and content replication are structurally relevant. However, any current application must be reviewed for mandatory bootstrap nodes, network population, data retention guarantees and the ability of two ordinary peers to exchange and retain content without separately provisioned always-on infrastructure.

Retain this as a historical reference until present-day clients and their constraints are independently checked; do not describe old plugins as active products without evidence.
